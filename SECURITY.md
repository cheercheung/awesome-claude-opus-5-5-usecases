# Security

This is a curated content repository, not an executable model client. Its build and validation scripts operate on local data. Source links and videos lead to third-party sites and do not imply endorsement.

Do not submit API keys, session cookies, private URLs or personal data. If you discover an exposed secret, broken trust boundary, or unsafe repository script, report it privately to the repository owner using an existing contact channel. Include the affected file and a minimal reproduction without revealing credentials. Routine source or attribution corrections belong in the correction template.
