# Contributing

Submit a concrete Claude Opus 5.5 workflow, demo, comparison, integration, tutorial or limitation using the case template. Include the original public source, publisher, date, a factual takeaway and all relevant attachments. Disclose affiliations and describe what was actually tested. Launch news, unsupported hype and repeated footage are not separate cases.

Edit `data/use-cases.json`, not only the generated README. Preserve stable source identities and the intake-number mapping. Run `python3 scripts/build.py` and `python3 scripts/validate.py` before submitting a change. Keep all available locales aligned. See [maintenance](docs/maintenance.md) for the complete process.

Original media and quoted works retain their owners' rights. Do not submit secrets or private materials. Attribution and removal requests can use the correction issue template after publication; for this local edition, provide the same fields directly to the repository owner.
